# Notion 成片上传

在制作单的「成片与发布」中先选时间线，再点「上传到 Notion」。入口位于时间线工具下方、TikTok 发布登记之前，未发布的视频也能上传。

上传窗口可核对成片完整路径、发布日期、发布账号、标题和 tags、钩子屏显及中文。英文和中文正文取这张制作单的口播版本；时间线已有屏显时优先用它。成片保存到 Notion 的「文件和媒体」，页面正文放中英文案和屏显，视频不在正文重复插入。

首次使用点「连接 Notion」，打开返回的授权链接，并允许访问目标发布日历及关联的账号列表。连接凭据由本机 Codex 管理，不需要在工作台保存 API key，也不会运行 AI 模型。授权完成后可关闭授权页，回到上传窗口继续。

超过 20 MiB 的视频会用 FFmpeg 生成上传版，保留原成片。上传在后台进行，关闭窗口后仍会继续。上传中不要重启或恢复工作台数据。失败后可以重试，已建立的 Notion 页面会接续更新；同一时间线再次上传会更新原页面。

成功后显示「查看 Notion」，并同步工作台的发布日历日期和已上传标记。这不等于登记 TikTok 发布，也不会把脚本改为已发布。

目标日历保存在本机 `config.local.json` 的 `notion_upload` 中：`name` 是显示名称，`data_source_id` 是 Notion 数据源 ID，`accounts` 可把制作人名称映射到 Notion 账号列表的用户名。日历需要「名称」「日期」「发布账号」「标题＋tags」「文件和媒体」属性，关联账号列表需要「名称」「Username」「Nick Name」。配置不包含密钥。

上传快照、请求恢复记录和原成片保存在 `runtime_root/production/notion-uploads/`，随工作台完整备份保存；重启备份仍只包含记录，不包含视频。
