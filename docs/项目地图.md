# 项目地图

想改某个功能，先在这里找到业务线，再看对应文件。新增或删除文件后运行 `python scripts/check_project_map.py`，它会列出地图里漏记或已失效的文件。

## 工作台怎么运转

```text
用户声音 → 内容方向 → 内容创作 → 视频制作 → 发布登记 → 带货数据与复盘
                                                         │
                                  经验和结论回到下一轮写稿 ←┘
```

- 浏览器打开 `static/index.html`，页面通过 `/api/...` 调用本机服务 `server.py`。
- `server.py` 负责接收请求，具体业务交给下面各业务线的文件。
- 真实业务数据保存在项目内，位置见[数据在哪里](#数据在哪里)；数据不纳入源码 Git。

## 命名规律

| 文件名 | 含义 |
|---|---|
| `xxx_store.py` | 负责读写这条业务线的数据 |
| `workbench_xxx.py` | 接口背后的业务流程 |
| `xxx_bridge.py` | 调用外部程序，如 Claude、Codex、达芬奇 |
| `tests/test_xxx.py` | 后端测试；以 `_ui` 结尾的是浏览器测试 |

**容易混淆：** `review` 有两种意思。`review_store.py`、`review_taxonomy.py`、`review_opportunities.py` 是**用户评论**；`review_policy.py`、`review_followups.py`、`review_experiences.py` 是**视频复盘**。

## 数据在哪里

路径由 `config.json` 和本机的 `config.local.json` 决定，`config.local.json` 优先。本机案例、运行资料和销售原表集中在项目的 `工作台数据/`；个人技能代码仍由桌面 `skill/` 管理。旧数据路径只保留指向项目内的兼容目录链接。

| 配置项 | 目录 | 内容 |
|---|---|---|
| `skill_root` | `工作台数据/案例库` | 案例记录、产品资料、来源文档和删除登记 |
| `skill_code_root` | 桌面个人技能主目录 | 案例技能代码和操作规则；不作为业务数据目录 |
| `runtime_root` | `directions` | 卖点与测试方向 |
| | `creation`、`revisions` | 稿件、内容列表与修改版本 |
| | `ai-tasks` | AI 任务与每轮结果 |
| | `reviews`、`evidence` | 用户评论库、证据与产品标注 |
| | `production` | 制作单、配音、发布登记 |
| | `library` | 案例视频与媒体 |
| | `performance` | 销售数据库 |
| | `davinci-ledger` | 剪辑台账 |
| 代码目录 | `archive/data-backups`、`archive/logs` | 重启时的备份和归档日志，别移走 |
| 代码目录 | `图文素材` | 完整备份会读取，别移走 |
| `performance_sources` | `工作台数据/销售原始数据` | 销售原始表 |
| 项目数据 | `工作台数据/关联原文件` | 恢复备份发现的外部引用文件副本及路径清单；其他软件使用的原件不移动 |

**两种备份范围不同：**

- **重启备份**（`launcher_control.py` 的 `BACKUP_SOURCES`）：包含方向、稿件、版本、AI 任务、评论、导航分配、案例资料，以及制作单、发布登记、配音 MP3、销售数据库、证据和剪辑台账。`production`、`library`、`performance`、`evidence` 只留记录：**不含图片、视频和 WAV，也不含缓存和一次性旧库副本。**
  - **保留：** 最新 14 份完整备份，再加最近 14 天每天最新一份。比上一份完整备份明显变少（某一来源的文件数不到一半，或核心目录缩到一成以下）的备份，文件名带 `-thin`，只保留最新 5 份，不占完整备份名额，并记入 `launcher-error.log`。比较基准超过 30 天后自动更新，刻意的大清理不会一直被当成丢失。
  - **恢复：** 先停服务，选最新且不带 `-thin` 的备份，把 `runtime/` 解压到 `runtime_root`，把 `skill/` 解压到 `skill_root`。
- **完整备份**（`data_backup.py`）：包含运行目录的大部分内容和 `图文素材`，只排除缓存、临时文件和登录凭据；媒体只有这里有。在设置页导出，或开启自动备份。本机已开启：每周一次（02:00），保留 3 份，存放在 `archive/完整数据备份/`，清理时只删自动备份登记过的文件，同目录的恢复包不动。备份目录只能放在 `archive/` 内或项目外。

## 根目录其他内容

| 位置 | 用途 |
|---|---|
| `tests/` | 全部测试，日常不用看 |
| `docs/` | 安装、教程和历史更新 |
| `使用说明.md` | 面向使用者的完整说明 |
| `reports/` | 审查报告，部分界面测试也会写入截图 |
| `图文成品`、`图文提示词` | 旧图文资料，旧任务和技能还引用这些路径 |
| `deployment/` | 公网站点的构建与部署工具，`site/` 是生成结果 |
| `sources/` | 案例文档模板 |
| `工作台数据/` | 案例库、运行资料、销售原始表和关联文件副本；迁移前副本在 `archive/数据迁移前-*`，恢复备份在 `archive/完整数据备份/` |
