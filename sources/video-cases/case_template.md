# 案例文件模板 (Case File Template)

反推案例的唯一结构。聊天、导出、入库都用这一份；只写对下一条脚本有用的信息。

规则：
- 结构：YAML frontmatter → 一个 H1 → 下方八个编号 H2。H2、H3、表头、固定字段表首列都不改名、不增删、不调顺序。
- 精简：每格一句话，每个 H3 不超过 3 句；不复述模板说明，不写通用道理，同一事实只写一次。
- 缺资料不删项，原位写“未提供”“未核验”或“原片无此项”，不编造口播、画面、价格或效果。
- 原片里的数字和经历写成说话者声称；没有销售数据不下“有效/爆款”结论。
- `<!-- fixed-rows -->` 只供校验读取，正文不用复制。动态表行数和第 8 章段数按原片定。
- 交付前运行 `validate_case_structure.py --strict-content --case-file "<文件>"`；通过不代表内容已核验。

```yaml
---
library_id: null                  # 正式保存时由案例库分配
case_structure_version: 1
tier: null
title: "案例的具体主题"
short_name: "索引短名"
category: null
category_display: "中文品类"
duration_sec: null
skeleton_id: null                 # 能核对到既有骨架才填
hook_types: []
evidence: {views: null, units: null, gmv: null, source: "数据来源与截止日"}
transcript_status: none           # verified（真实音频+时间戳）| inferred | none
---
```

## 1. 案例基本信息

### 基础资料

<!-- fixed-rows -->
| 字段 | 内容 |
|---|---|
| 产品 | 产品名与品类 |
| 视频数据 | 播放 / 件数 / GMV 及来源截止日；没有写无 |
| 视频时长 | 秒数及来源 |
| 来源 | 账号、原帖链接或文件 |
| 分析日期 | 本次日期 |

### 脚本主线判断

一句话主线，一句话购买理由（观众为什么要买，不是参数复述）。

### 核对范围

看了什么（抽帧数、转写、评论、数据），没看什么。

## 2. 钩子 (Hook) 拆解（含屏显贴纸）

### 开场要素

<!-- fixed-rows -->
| 字段 | 内容 |
|---|---|
| Hook 类型 | 钩子方式；对不上既有框架就直接描述 |
| 口播 | 原文（中文意思）；无写无 |
| 屏显 | 原文（中文意思）及出现时窗；无写无 |
| 开场画面 | 第一眼看到的动作和物体 |
| 为何有效 | 结合具体文字与画面的判断 |

## 3. 叙事结构拆解（五步法对标）

### 逐句写作决策

| 时间 | 句子 | 作用 | 与前句连接 |
|---|---|---|---|
| 原片时间 | 原句或忠实语义 | 建立兴趣 / 给证据 / 处理顾虑 / 引导购买等 | 怎么接住上一句；首句写怎么开场 |

### 卖点与证据

主卖点、支撑它的机制证据、购买理由，各一句；原片没有就写无。

## 4. 骨架匹配与反查

### 骨架匹配

<!-- fixed-rows -->
| 特征 | 匹配项 |
|---|---|
| 匹配骨架 | 编号（与 frontmatter 一致）或“未匹配” |
| 结构特征 | 原片可见的顺序与连接 |
| 与参考的差异 | 本片怎么变的；不为套库改原片 |

## 5. 口播原文完整转写

### 完整原文

一行写转写来源和精度。`verified` 必须逐段带时间戳；没有转写写明原因，不编原文：

```text
[0.00s - 3.60s] {真实口播}
```

### 完整中文语义

| 时间 | 中文语义还原 |
|---|---|
| 与原文对应的时间 | 完整中文 |

## 6. 视觉节拍详解

### 视觉节拍表

| 时间 | 画面 | 屏显文字 | 作用 |
|---|---|---|---|
| 原片时间或核对帧 | 看到的事实 | 当时可见文字或无 | 对理解或购买的作用 |

## 7. 关键成功因子（可复用策略）

### 可复用策略

首句写效果证据状态（有无销售数据）。再列 1–3 条：策略 → 原片依据 → 怎么复用；证据不够就少写。

### 创作取舍

<!-- fixed-rows -->
| 槽位 | 本案例的取舍 |
|---|---|
| 受众切入 | 对谁说，依据 |
| 核心矛盾 | 驱动观看的问题或愿望 |
| 最强转化桥 | 哪句或哪个画面把兴趣转成购买；没有如实写 |
| 未占用角度 | 原片没用的卖法 |

## 8. 可复用脚本骨架

### 原片结构变量化

按原片顺序抽象，段数随原片；缺内容时写 `[未核验｜待补原片结构]`：

```text
[原片时窗｜该段功能]
“{变量化句式}”
画面：{这一句需要的画面}。
```
